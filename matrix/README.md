# 母体条目库

从 `knowledge/10-东海母体素材.md` 索引的资料中提炼的**可直接调用的事实条目**。

写故事卡、做母体解码时查这里，不要回头翻原书。

## 条目卡格式

每条五栏，缺一不可：

```
### 条目名（异名 / 土名 / 古名）
- **适用范围**：玉环本地 | 浙江 | 东海通用 | 邻域参照（象山·舟山）
- **事实**：<重述，不抄原文>
- **出处**：《书名》(版本) 编/章/节 或 页码
- **核实状态**：✅已核 | ⚠️待核（OCR 存疑处逐项标出）
```

## 适用范围的硬规则 ⚠️

海岸商店首店在**浙江台州玉环**。

- 只有标 **`玉环本地`** 且核实状态非 ⚠️ 的条目，才能写进面向首店的产品文案。
- **`邻域参照`** 的条目（象山、舟山）只能用来学**做法与结构**，绝不可当作玉环的事实写出去。舟山话和台州话不是一回事，象山的开渔节不是玉环的开渔节。
- **`东海通用`** 可用于品牌层的大方向表述，但落到具体器物时仍需本地佐证。

## 关于 ⚠️ 待核

这批资料全是扫描 OCR，专名和数字错误率高。凡标 ⚠️ 的：

- **物种名** —— 须与权威名录核对学名后再用
- **数字** —— 面积、产量、年份、海拔一律先当作不可引用
- **土名** —— 最好由本地人或方言材料复核

**留空好过写错。** 主打在地的品牌，一个错的鱼名会被本地人一眼看穿。

## 已确立的三条骨架

从《玉环县志》(1994) 提炼出的三条，是后续所有创作的地基：

1. **方言三分** —— 玉环一县两大语系三个方言片（坎门闽南片 / 鲜叠瓯语 / 楚门台州片），对应三拨移民、三种生计。**「玉环」作为单一母体站不住，真正的母体是这个交汇本身。**（`04-语汇.md`）
2. **渔汛挂节气** —— 冬至毛虾、立秋钓批带、乌贼三水（雨水/立夏水/小满水）、黄鱼对清明至端阳。**一条船的一年，节气走完。**（`02-生产.md`）
3. **衰退是事实不是修辞** —— 志书明载 70 年代后大黄鱼、乌贼、毛虾衰退，小黄鱼、海蜇濒临绝迹，黄鱼对 1973 年始歇。**任何「丰饶东海」的调门都与本地志书矛盾。**（`01-物种.md`）

## 三个可直接用的核心符号

从素材里浮出来、且有出处、且分量足够撑起一条产品线的：

| 符号 | 出处 | 为什么成立 |
| --- | --- | --- |
| **「一风」** | 县志·渔业生产习俗 | 海上工钱的计分单元 —— **从风静出海至起暴入港为一风**。不是时间也不是距离，是一段风的长度。一个渔民的一生由许多「风」组成 |
| **「开船目」** | 县志·船祭 | 新船落水，以内置银元的沸水（**「银汤」**）淋浇船眼，为船开目。**志书明写此俗仍存** —— 是活的仪式，且天然就是开箱仪式的原型 |
| ⚠️ ~~「网鱼捕虾，捉蜇钓带」~~ | 清代官方文书 | **已撤下** —— 原文后接「藏垢纳污」，是对海上流民的判词，非赞美渔业。改作**身世叙述**使用，见 `02-生产.md` |

配套的次级符号：「冬至毛虾」「钓批带」「打春船」「宜将煮海作耕田」「吃鱼不翻身」「大船让小」。
