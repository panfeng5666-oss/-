**三本的分工**

- **摩根**：手感与实操。全书结构为 视觉营销发展史 → 视觉陈列师角色 → 店铺设计（含快闪店）→ 橱窗展示（陈列区域 / 色彩 / **灯光** / 标示与图案 / 设计日程表 / 标准维护与预算）→ 店内陈列（品类陈列 / 素材布置 / 加价体与样品 / 清仓 / 标志标记 / 科技手段与数码视觉营销）→ 人形模特 → 陈列师工作室（工具箱 / 健康与安全）→ **衡量成效**。每章末附国际品牌访谈（路易·威登、巴黎老佛爷、Kurt Geiger、哈罗德百货、航班 001 等）。**"衡量成效"与"标准维护与预算"两章是本库最缺的部分** —— 它们把陈列从审美变成可考核的事。
- **Pegler & Kong**：术语与规范。系统性最强，陈列构图法则、季节换陈周期、道具与装置分类的标准表述以此为准。
- **Ebster & Garaus**：实证依据。店铺氛围学（store atmospherics）的实验研究 —— 色彩、音乐、气味、动线布局对停留时长与成交的实际影响。与知识库 07 的《顾客为什么购买》互补：昂德希尔靠观察，这本靠实验。**Skill 中"四感开箱仪式"与"触碰即成交"的主张，理论后台在这里。**

## 四、术语口径提醒 ⚠️

Skill 中使用的 **VP / PP / IP 三级点位**是**日系 VMD 体系**的术语。本库新增的三本均为欧美体系，用的是另一套词：

- 摩根：window display（橱窗）/ in-store display（店内陈列）/ 品类陈列
- Pegler：display / presentation 的分类体系
- Ebster：store atmospherics（店铺氛围学）

**这不影响方法本身**（焦点—场景—单品的三层逻辑是通用的），但**对外提案时若要标注出处，需注意 VP/PP/IP 这组缩写在这三本里可能找不到原词**。要么按欧美术语改写，要么另找日系 VMD 教材坐实。
