## 跨库的三条理论链条

值得注意的是，这批藏书之间存在明确的互补关系，调用时应成组取用：

1. **意义构造链**：荣格《红书》→ 坎贝尔《千面英雄》→ Lakoff《我们赖以生存的隐喻》→ 巴特《神话修辞术》→ 华杉《超级符号就是超级创意`》（08 + 01）
2. **日系极简链**：原研哉《设计中的设计》→《极简之道》→ MUJI《思考与话语》→ 柳宗悦民艺五册（03 + 05）—— 视觉与文案共用一套语汇
3. **量产落地链**：Lefteri 五大材料 → Thompson《工艺全书》→ 孙诚《包装结构设计》→ 潘松年《包装工艺学》（06）—— 平面刀版需跨库取 06
4. **溢价论证链**：《礼物经济》→ 老铺黄金两份深度报告 → 豫园东方生活美学战略（09）→《超高价营销》（08）—— 高价位文创的定价，理论与实证在这条链上齐了

## 知识库 10 的特殊性

01~09 是**方法**，10 是**素材**。方法可以通用，素材有地理边界 —— 海岸商店首店在浙江台州玉环，而现有海洋文化藏书覆盖的是浙江省级、舟山、象山、江苏、厦门。

因此 10 不直接调用，而是提炼为 `matrix/` 下的条目卡，每条标注**适用范围**（玉环本地 / 浙江 / 东海通用 / 邻域参照）。**只有「玉环本地」且已核实的条目可写进首店产品文案。** 详见 `matrix/README.md`。
