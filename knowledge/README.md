## 补录方式

按 `05-器物叙事与微内容.md` 的格式，分模块列出：

```markdown
## 一、<模块名>

| 书名 | 作者 / 译者 | 出版社 | Drive 文件 |
| --- | --- | --- | --- |
| **《书名》** | 作者 | 出版社 | `文件名.md` |

**核心价值**：<这批书为该 Skill 提供的具体能力>
```

补录后同步更新本文件的索引表与 `00-Drive资料总索引.md`。
