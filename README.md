> **Chifang Guwu** —— 一套面向海岛非标空间、买手店与文商旅品牌的文创设计运营系统库。

## 一、这个库是什么

从符号提炼到店员话术，把"一个文化母体如何变成一件能卖出去、还能被讲述的器物"拆成 7 个可独立调用、也可联合调用的系统。每个系统是一个 Skill，放在 `.claude/skills/` 下，在 Claude Code 中按需自动触发。

```
                          【全链路协同作业全景】
  ┌────────────────────────────────────────────────────────────────────────┐
  │ 1. 🧠【符号学系统】  ──> 解码文化母体 / 提炼超级符号 / 逆向爆款诊断    │
  ├────────────────────────────────────────────────────────────────────────┤
  │ 2. 🏺【文创设计系统】──> 80/20商业闭环 / 三层产品矩阵 / 在地CMF初选    │
  ├────────────────────────────────────────────────────────────────────────┤
  │ 3. 🎨【平面视觉系统】──> 栅格版式蓝图 / 包装刀版 / 工业级生图Prompt    │
  ├────────────────────────────────────────────────────────────────────────┤
  │ 4. 🏬【空间展陈系统】──> 策展零售规划 / VMD点位(VP/PP/IP) / 空间效果图 │
  ├────────────────────────────────────────────────────────────────────────┤
  │ 5. 📜【器物叙事系统】──> 随盒风物故事卡 / 风琴折Zine / 四感开箱仪式    │
  ├────────────────────────────────────────────────────────────────────────┤
  │ 6. 🏭【供应链品控系统】─> 工业级BOM拆解 / 工艺交底书 / 大货QC质检表    │
  ├────────────────────────────────────────────────────────────────────────┤

  └────────────────────────────────────────────────────────────────────────┘
```

## 四、怎么用

在本仓库目录下启动 Claude Code，直接用自然语言下需求，Skill 会按关键词自动触发。

**单系统调用**

```
我们为海岛非标空间开发了一款"东海海盐与耐候红钢镇纸"，请撰写：
150 字随盒风物故事卡定稿；四感开箱仪式设计方案（含内盒文字彩蛋）；
一篇 300 字主理人生活手记体小红书种草文案；器物底部的 4 字暗刻铭文。
```

**全链路联合调用**

```
我们计划为海岛非标空间企划一款"海盐冷萃咖啡豆与粗陶随行杯"礼盒，
请联合调用全部系统，输出：符号学文化母体与超级符号提炼；三层产品谱系定位；
包装平面排版蓝图与 Midjourney 生图 Prompt；咖啡馆 1 平米文创展陈 VMD 方案；
随盒风物故事卡与四感开箱仪式；工业级 BOM 成本拆解表与大货 QC 质检标准；
咖啡吧台店员 30 秒 Story-Selling 话术与收银交付仪式 SOP。
```

两条指令的完整产出见 `samples/` —— 但请注意，那是**功能测试样例，产品为虚构命题**，只可参照交付结构，其中数字均为演示值。真实项目请沉淀到 `cases/`。

## 五、知识库说明

原文存放在 Google Drive 的 **`赤方古务`** 与 **`品牌营销`** 两个文件夹，`knowledge/` 只放**索引与书目清单**，不放原文，也不要把原文提交进本仓库。

10 个知识库、Drive 文件夹结构与全部 Drive ID，见 `knowledge/00-Drive资料总索引.md`（2026-09-03 盘点）。

各知识库支撑度不一，`knowledge/README.md` 里有一张「文献支撑度 × Skill 可信度」对照表，以及四条**跨库链条**（意义构造链 / 日系极简链 / 量产落地链 / 溢价论证链）—— 调用时应成组取用，而不是单库孤立使用。

2026-09-05 补入 VMD 三本（摩根 / Pegler / Ebster）、照明一本（Karlen & Benya）、色彩管理两本（Fraser《Real World Color Management》、《印刷色彩学》），三处大缺口全部补上。

**剩余的是"标准"而非"方法"** —— 方法论都齐了，缺的是三份可对外引用的权威数值来源：`GB 50034` 建筑照明设计标准、`GB/T 23863` 博物馆照明设计规范、`ISO 12647` 印刷容差。另需实体 Pantone 色卡（书替代不了）。在此之前，Skill 产出的照度与 ΔE 数值应视为有依据的建议值，交底或付印前与灯光顾问、印厂复核。
