### 母体归一：**「一风」**

> 海上生产以「风」为计分单元。**从风静出海至起暴入港为「一风」。** 以本风全部大宗鱼货所得净利，船主抽五成，余按船、网渔具、伙计各一份分红，「走台」半份。
> —— 《玉环县志》(1994) 第二十四编 · 生产习俗 · 分红

**为什么是它**

1. **它是一个计时法，而不是一个物。** 物会被模仿，计时法不会。竞品可以做海浪纹样、可以用粗陶，但拿不走「按风算工钱」这件事。
2. **它的代偿最准。** 都市客群的时间被切成均等格子——打卡、工时、日程、番茄钟。「一风」是另一套：**不由人定，由自然定；不均等，每一风长短不同；有始有终，中间不可分割。** 一风里没有半小时的概念，风起了你就在里面，直到它停。这不是「松弛感」那种软诉求，对准的是**对均质时间的疲惫**。
3. **可述性极强。** 一句话讲完，讲完对方会「哦」一声——这个「哦」就是记忆点。
4. **需要解释，是优点不是缺点。** 需要解释的东西才需要故事卡，才需要店员开口，才有 Skill 5 和 Skill 7 的用武之地。

**弱项与对策**：可视化难度最高（风本身不可见）。对策见模块四——不画风，画**一风的形状**。

### 仪式层：**「开船目」**

> 闽籍渔民起季出海前，在船上烧一锅沸水，内置一银元，俗称**「银汤」**，淋浇船眼，俗称**「开船目」**……**新船落水「开船目」遗俗仍存。**
> —— 《玉环县志》(1994) 第二十四编 · 生产习俗 · 船祭

它不是第二母体，是**进入母体的入口**：一件器物先被「开目」，此后陪你度过许多「风」。

⚠️ **地理层级提醒**：志书原文作「**闽籍**渔民」。这是**坎门一带闽南渔民**的习俗，**不宜表述为「玉环人的习俗」**。正确说法：「玉环坎门的闽籍渔民有此俗」。

## 模块二：三元符号转译表（Peirce Trichotomy）

| 层 | 转译对象 | 落到器物的具体特征 |
| --- | --- | --- |
| **像似符 (Icon)** | 「一风」的**形状**——不是风的形状，是**一段有始有终的过程**的形状 | 器物表面一道**自平至隆再收束**的纹理段：起于平静、中段隆起、末端回落归平。可为拉坯旋纹的一段起伏、金属的一道锻打隆脊、纸面的一处压凸 |
| **指示符 (Index)** | 风与盐真实作用过的**物证**（此层不可伪造） | · **拷汁染的深赭色**——渔民衣以拷汁染、其色深赭（县志·生活习俗），是劳动的真实痕迹<br>· 海风侵蚀的木、石、金属的自然氧化面<br>· 盐结晶（风带海水上岸、蒸发留盐）<br>· 长期握持形成的包浆 |
| **象征符 (Symbol)** | 抽象几何图形，见模块四 | 基线上隆起的单弧；其镜像扣合即成眼形 |

**转译纪律**：指示层是这套符号的**诚信底线**。深赭色必须真是拷汁或同类天然染，氧化面必须真是海风所致。**一旦指示层作假，整套符号就塌了**——因为它宣称的正是「真实作用过」。

## 模块三：二级神话叙述稿（Barthesian Myth）

**一级意指**：一件器物（一只杯、一方镇纸、一张纸品）。

**二级神话**：**一件按「风」计时的物。**

**升维路径**：

```
器物  →  被「开目」的器物  →  陪你度过许多「风」的器物  →  另一套时间的凭证
（物）    （仪式赋予它开端）    （劳动与陪伴的计量）        （对均质时间的抵抗）
```

**神话表述**（供 Skill 5 展开）：

> 你的一天被切成很多格。海上的人不这么算。
>
> 他们按「风」算——从海面静下来出港，到风起来入港，中间叫一风。一风有长有短，不由人定。工钱按风算，不按天算。
>
> 这只器物在离开我们手里之前，被开过目。此后它跟着你，过你的风。

**情绪靶心**：不是「治愈」「松弛」「陪伴」这类通用软诉求，而是**对被均分的时间的疲惫**。这个靶心更窄，但更硬——打中的人会立刻认领。

⚠️ **语气红线**：`matrix/README.md` 第三条骨架——志书明载 70 年代后大黄鱼、乌贼、毛虾衰退，小黄鱼、海蜇濒临绝迹，黄鱼对 1973 年始歇。**本母体不得配「丰饶东海」「向海而生」一类调门**，与本地记载矛盾。「一风」的底色是劳动与消逝，不是丰饶。

## 模块四：超级符号设计说明

### 图形：**一风**

**构图逻辑**：一条水平基线，中段隆起一道单弧，两端回落至基线。

```
        ╭─────╮
───────╯       ╰───────      「一风」：静 → 起 → 静
```

- 基线总宽 **3 单位**，弧高 **1 单位**（3:1）
- 弧的起止点各距端点 **0.5 单位**（左右留白对称）
- 全图仅一条连续线，**无断点、无细节、无填充**

### 双态设计（本方案的核心巧思）

单弧与其上下镜像扣合，即成**眼形**：

```
        ╭─────╮
───────╯       ╰───────        开态 · 一风（劳动进行中）
        ╰─────╯

     ╭───────╮
    ╱         ╲                 合态 · 船目（器物已开目）
    ╲         ╱
     ╰───────╯
```

**一个图形，两种状态**：开态是一风的过程，合态是被开目的眼。**符号自身就承载了模块三的整条神话链**——这是本方案最值得保留的部分。

### 技术规格

| 项 | 规格 |
| --- | --- |
| 最小识别尺寸 | **8mm**（单线无细节，可满足） |
| 单色适配 | ✅ 本就是单线 |
| 烫印 / 烫金 | ✅ 线宽建议 ≥ 0.3mm |
| 镭雕 / 器物暗刻 | ✅ 适合 4~6mm 微雕 |
| 击凸 / 压凹 | ✅ 单弧无锐角，不易爆线 |
| 刺绣 | ✅ 可走单股链式针 |
| 火漆印章 | ✅ 合态（眼形）更适合圆形印面 |

**延展建议**：多个「一风」首尾相接可成连续边纹（一年是许多风）；不同弧高可作产品线区分（长风 / 短风）。

## ⚠️ 更正记录（2026-09-06）

### 「网鱼捕虾，捉蜇钓带」的语义误读

**初稿错误**：将此十二字列为超级话语第一候选，描述为「清代旧志对玉环渔业的记述，八字四作业，节奏工整」。

**实际原文**（《玉环县志》(1994) 附录·艺文，雍正玉环展复时的官方文书）：

> 当未开垦以前，闽、广、温、台各处**匪类**，皆搭棚厂，聚集海屿……沿海刮土，公行私贩之盐，或群聚垦畲，坐收无税之产。**网鱼捕虾，捉蜇钓带，船艘千余，藏垢纳污。** 今**流民尽行驱去**，而所招募开垦者，乐清、太平、平阳、永嘉四县**良民**……

**错在哪**：只截取了半句，未看上下文。紧接其后的四字是**「藏垢纳污」**，随后是「流民尽行驱去」。这不是对渔业繁荣的记述，是**官方对海上流民的判词**。

**处置**：
- 此句**不得作为正面引文**用于品牌溯源或店内导视。
- 但它的价值不降反升 —— **作为身世叙述使用**：前十二字是他们的生计，后四字是朝廷的定性。**在官方眼里被驱逐的那批人，正是最早在这片海上打鱼的人。**

### 由此浮出的身世层，并入主母体

雍正展复的人口置换：**海禁空岛 → 闽广温台流民聚居打鱼 → 定性「匪类」「藏垢纳污」→ 尽行驱去 → 招乐清、太平、平阳、永嘉四县「良民」入垦。**

**它把此前各条素材串起来了**：

1. **方言三分有了来源** —— 鲜叠话（瓯语／永嘉）、楚门话（台州片／太平即温岭）来自招募的「良民」四县；**坎门的闽南人与被驱逐的「闽广」流民同源**。两拨人的身份从一开始就不同。
2. **「一风」的性格有了根** —— 按风分红、不按天算，本就是不服从官方历法与税制的计时法，与「坐收无税之产」是同一种生存逻辑的延续。**一风不只是浪漫的自然计时，它带着体制外的来历。**

**对二级神话的影响**：模块三的情绪靶心「对被均分的时间的疲惫」依然成立，但底层多了一重更硬的东西 —— **一风是一种未被收编的时间**。

### 书名更正

初稿作《特开玉环厅志》，正确书名为**《特开玉环厅志》**（张坦熊主持编修，4 卷）。另有光绪《玉环厅志》14 卷 + 补遗 1 卷。

### 方法教训（已写入纪律）

**引用旧志原文必须读上下文，不得截半句使用。** 一句话的褒贬，往往在它后面那四个字里。

## ⚠️⚠️ 母体改判（2026-09-07）

主理人确立 **「海边小子」为总 IP，是所有海岸 IP 的总和**。据此，本案的母体归一结论作如下调整：

### 新的主从关系

| 原 | 现 |
| --- | --- |
| 主母体 = **一风** | 主母体 = **海边小子** |
| 仪式层 = 开船目 | 一风 = **他的计时法**（他不按钟点过日子，他按风） |
| 身世层 = 驱流民·招良民 | 开船目、身世层保持不变，均为他所处世界的构成 |

**改判理由**：一风是一套法则，法则无法承载价值观、无法被陈列、无法生长出产品谱系。**而一个人可以。** 店里所有东西都跟他有关 —— 不是"印着他的形象"，是「**他捡的**」或「**他做的**」，每个新品因此自带来历。

**一风并未削弱**。它从"世界的法则"变成"**这个人身上的一个属性**"，反而更好懂、也更好爱 —— 一个具体的人有一套怪计时法，比"这个世界有一套计时法"容易传播得多。

### 超级符号：一图三义（模块四的扩展）

原设计为「基线上一道弧，镜像扣合成船目的眼」。海边小子进来后，**同一道弧多出第三重身份**：

| 身份 | 含义 |
| --- | --- |
| **一风** | 静 → 起 → 静，一段风的长度 |
| **船目** | 弧与镜像扣合成眼 |
| **海边小子** | **弯腰捡东西的背影** |

**符号系统无需重做 —— 它本来就在等这个人出现。**

### 二级神话的重写

原表述靶心为「对被均分的时间的疲惫」，仍成立，但**叙述主体从"海上的人"收拢到一个具体的人**：

> 他捡别人不要的东西。
> 玻璃碎了，被丢进海里。海磨了它二十年，磨掉所有锋利的边，磨成一颗温的、钝的、半透的东西。他弯腰把它捡起来。
> 他不觉得这是变废为宝。他觉得是**海把活干完了，他只是弯了个腰**。

### 「衰退」的落点再次收敛

由「**守**」进一步收敛为「**捡**」——守仍是防御姿态，捡是主动、日常、不悲壮的。

> **海退了。但退潮之后，有东西可捡。**

详见 `doctrine/海边小子.md`。

## 补记（2026-09-06 · 与东海珍奇柜纲领的扣合）

母体解码完成后，主理人确立了 `doctrine/东海珍奇柜纲领.md`。「一风」与珍奇柜体系可严丝合缝扣上：

**珍奇柜的血统里本来就有海。** 它是大航海时代的产物 —— 船从远方带回异物，贵族收进柜子；柜子成为微缩宇宙，因为世界是被**航行**带回来的。赤方古务的版本只是把「贵族与远洋船」换成「渔民与一风」：

> **一风是采集的单位，珍奇柜是采集物的归所。**
> 渔船带回东海的异物，收进海岸商店。每一件都标着它是第几风带回的。

三分与 `matrix/` 的对应，以及 **Scientifica 空缺即最大机会点**（「一风」本身是一种测量，需要一具仪器）—— 详见纲领。

这一扣合同时补上了本案模块四的一处不足：超级符号原设计只承载了「一风↔开目」的开合双态；纳入珍奇柜后，符号还多了一重身份 —— **藏品编号的载体**（每件藏品标注第几风）。
