# 符号学与超级符号系统 (Semiotics & Super Symbol System)

> ⚠️ **来源说明**：本 Skill 由 `docs/需求来源-GeminiSpark导出.md` 中记录的系统全景与实战案例产出反向还原，非原始 Instructions 全文。若你手中留有该 Skill 的原始正文，请直接覆盖本文件。

## 概述与核心哲学

本系统以"一切品牌资产都是符号资产，一切购买都是对文化母体的条件反射"为核心，把在地文化、集体记忆与自然物候解码为可被消费者 0.3 秒识别的超级符号与超级话语，为后续产品、平面、空间、叙事全链路提供统一的符号原点。

## ⚠️ 纲领约束（优先于下列默认做法）

本 Skill 受 `doctrine/东海珍奇柜纲领.md` 约束：

- **二级神话按博物志逻辑构造，不按英雄之旅构造。** 意义的升维靠「物的来历、流变与误传」，不靠情节与主人公。
- 母体须能容纳 **Wunderkammer 三分**（Naturalia／Artificialia／Scientifica），即须是一个能收纳异物的世界观，而非一个故事。
- 遵守纲领的**三层分离原则**：实层有出处、述层是手艺、幻层须明示。

## 核心方法论与工程支柱（五位一体）

### 1. 文化母体解码 (Mother Matrix Decoding)

- **在地母体挖掘**：地理与物候（潮汐、季风、矿脉、窑口）、生产与技艺（渔盐、船坞、柴烧、草木染）、民俗与信仰（节令、祭祀、吉语、纹样）。
- **母体强度判定**：是否具备集体记忆共识、是否可视觉化、是否可复述、是否具备情绪代偿价值。
- **母体归一**：一个产品线只锚定 1 个主母体，避免符号杂音。

### 2. 三元符号转译 (Peirce Trichotomy)

将抽象母体逐层落到可制造的物理特征：

- **像似符 (Icon)**：形态的直接模拟（如粗陶杯身手工拉坯的潮汐波纹微弧面）。
- **指示符 (Index)**：因果与痕迹的物证（如陶胎中掺入的海砂颗粒触感、红钢的氧化火烧色）。
- **象征符 (Symbol)**：约定俗成的抽象图形（如极简几何"潮汐罗盘"）。

### 3. 二级神话建构 (Barthesian Myth / Second-Order Signification)

把"功能性商品"升维为"精神仪式"：

- **一级意指**：物本身的功能（一包咖啡豆 / 一块钢镇纸）。
- **二级神话**：功能之上的意义（"把海岛清晨与潮汐白噪音装进口袋" / "压住案头风浪的重力之锚"）。
- **情绪靶心**：对准都市客群的去班味、精神内耗、渴望松弛与陪伴。

### 4. 超级符号与超级话语提炼 (Key Graphic & Key Phrase)

- **超级符号 (Key Graphic)**：单一、几何、可缩放至 8mm 仍可辨识、可烫印可镭雕可刺绣的核心图形；须给出构图逻辑（如 3 组同心双向正弦波交汇）。
- **超级话语**：
  - *主标语*：7~12 字，具画面与动作感（如"潮退时晒盐，风起时煮海。"）。
  - *副标语*：12~20 字，直给消费者利益与情绪（如"一杯海盐冷萃，带走一捧东海的风。"）。
- **符号资产延展检查**：包装、器物暗刻、空间导视、店员话术、社媒话题是否共用同一符号。

### 5. 爆款逆向符号学诊断 (Reverse-Engineering Diagnosis)

对标竞品或既有爆款，逆向拆解：母体是什么 → 三元转译在哪几个物理点落地 → 二级神话如何叙述 → 超级符号的辨识效率 → 可迁移与不可迁移的部分。

## 产出与交付规范

1. **【文化母体解码报告】**：候选母体清单、强度评分与最终归一母体。
2. **【三元符号转译表】**：像似/指示/象征三层各自对应的具体材质、工艺与形态特征。
3. **【二级神话叙述稿】**：从功能到精神仪式的意义升维路径。
4. **【超级符号设计说明】**：构图逻辑、最小识别尺寸、单色/烫印/镭雕适配性。
5. **【超级话语体系】**：主标语、副标语、器物暗刻候选与社媒话题标签。
6. **【符号一致性检查清单】**：贯穿产品、平面、空间、叙事、零售五端的落地校验。
