# 海边小子

> **性质**：总 IP 与价值观纲领。与 `东海珍奇柜纲领.md` 并列为最高优先级，冲突时两者互补 —— 珍奇柜管**东西怎么归类与呈现**，本篇管**谁在做这件事、为什么做**。
> **确立**：2026-09-07

---

## 一句话

> **一个没有脸的小子，在一片退了潮的海边，弯腰捡东西。**
> **捡到的，他收进一个柜子；做出来的，他也收进去。他不说话，只记下来。**

---

## 一、他是 IP 的总和

海岸商店里所有的东西，都跟他有关。不是"印着他的形象"，是**"他捡的"或"他做的"**。

```
海边小子              一个憨小子，不说话，弯着腰
  ├ 他捡的   Naturalia    海玻璃、贝、骨、被冲上岸的东西
  ├ 他做的   Artificialia 器物、盐、染、绳
  └ 他量的   Scientifica  一风记、节气、潮汐
        ↓
  全部收进   东海珍奇柜（海岸商店）
        ↓
  全部记进   《东海风物图志》（他写的）
```

**这解决了 IP 增殖的合法性问题。** 一般文创出新品，理由是"我们又设计了一个形象"——外部的、商业的。这里新品出现的理由是"**他又捡到／又做了一个东西**"——内部的、叙事的。**每个新品自带来历。**

## 二、他的价值观

> **他捡别人不要的东西。**
>
> 玻璃碎了，被丢进海里。海磨了它二十年，磨掉所有锋利的边，磨成一颗温的、钝的、半透的东西。他弯腰把它捡起来。
>
> 他不觉得这是变废为宝。他觉得是**海把活干完了，他只是弯了个腰**。

### 海玻璃是他的自画像

它是**捡**的不是做的；本来是**被丢掉的**；**每一块都不一样**，天然限量；**成本几乎为零**，价值全在来历里；**需要有人愿意弯腰**。

它与本库既有素材全部咬合：

| 素材 | 咬合处 | 出处 |
| --- | --- | --- |
| **「藏垢纳污」** | 被朝廷驱逐的流民，也是"别人不要的" | 《玉环县志》附录·艺文 |
| **「走台」** | 船上做杂务、分红只拿半份的年轻人 | 县志第二十四编 |
| **资源衰退** | 海退了，但退潮之后有东西可捡 | 县志第四编 |
| **「物老则为怪」** | 物老了会成精 —— 海玻璃就是老了的玻璃 | 盛文强（《搜神记》） |

### ⚠️ 「衰退」的落点由此更新

`CLAUDE.md` 原定「衰退落在**守**上，不落在哀上」。现进一步收敛为 —— **落在「捡」上**：

- **哀** = 情绪、被动
- **守** = 行动，但仍是防御姿态
- **捡** = 主动、日常、不悲壮 ✅

> **海退了。但退潮之后，有东西可捡。**

这比任何「守护传统」的口号都不油，且与「憨」的调性一致。

## 三、他的形象

### 1. 他没有清晰的五官

出自陈丹青论梵高《海边的渔夫》（1882，海牙时期）——「一个小混蛋站在海边，**那个脸的五官都没有了**」，身体、裤腿、鞋子歪歪扭扭，显然是生手之作。陈丹青的判词是：**「艺术史上画得巧的人太多，而画得憨却是不易。」**

这不是缺陷，是本 IP 最要紧的设计决策：**不画脸，就不会掉进萌化陷阱；不画脸，每个人都能把自己放进去。**

### 2. 他总是弯着腰

因为他在捡东西。他的标准姿态不是站着、不是笑着，是**弯腰**。

### 3. 他带一个容器

桶、篓、兜，或只是撑开的衣襟。**容器是珍奇柜的最初形态。**

### 4. 他穿深赭

拷汁染。这是他身上**唯一有志书出处**的细节 —— 「渔民衣以拷汁染，其色深赭」（县志第二十四编）。

### 5. 他不说话

图志是他记的，东西是他捡的、做的。**但他从不出来解释。** 解释的是词条，不是他。

## 四、⭐ 弯腰的背影，就是那道弧

超级符号（见 `cases/01`）是基线上一道弧，镜像扣合成船目的眼。

**而一个弯腰捡东西的人的背影，也是那道弧。**

```
        ╭─────╮
───────╯       ╰───────
```

**一个图形，三重身份：**

| 身份 | 含义 |
| --- | --- |
| **一风** | 静 → 起 → 静，一段风的长度 |
| **船目** | 弧与镜像扣合成眼（开船目） |
| **海边小子** | 弯腰捡东西的背影 |

符号系统无需重做 —— **它本来就在等这个人出现。**

## 五、「一风」降格（2026-09-07）

**「一风」不再是世界的法则，降为海边小子身上的一个属性。**

> 他不按钟点过日子，他按风。

全部魅力保留，但不再与总 IP 争中心。**一个具体的人有一套怪计时法**，比「这个世界有一套计时法」好懂、也好爱。

`cases/01` 中「母体归一为一风」的结论据此调整：**母体归一为「海边小子」，一风是他的计时法。**

## 六、憨，不是萌

| | 萌 | **憨** |
| --- | --- | --- |
| 姿态 | 讨好 | **不讨好** |
| 来源 | 被设计出来 | **未被设计** |
| 感受 | 可爱 | **笨拙、真诚** |

纲领禁的是**萌**。**「憨」是「审美去油」的极端形式** —— 油是精明、圆熟、讨好；憨是不精明、不圆熟、不讨好。两者同路。

### 精工做拙形

「憨」与纲领「有重量、有机关」的要求，调和于此：

| 层面 | 取向 |
| --- | --- |
| **工艺** | **精** —— 该有的公差、该咬合的机关，一样不能少 |
| **造型** | **拙** —— 不追求优美流畅，允许笨重、不对称 |
| **命名** | **直** —— 「一风记」就是直白的，不叫「沧海拾光·潮汐记忆仪」 |
| **文字** | **笨** —— 只陈述，不修辞 |

这正是知识库 05 柳宗悦五册讲的民艺之道：工艺扎实，形是拙的、无名的、不炫技的。也是涩泽的路子：**文字精确冷静，对象荒诞可笑。形式精，对象憨。**

## 七、他是谁 —— 三层分离

| 他是什么 | 层 | 规则 |
| --- | --- | --- |
| **「走台」** —— 船上做杂务、分红拿半份的年轻人 | **实层** | 志书有载（县志第二十四编），可当事实写 |
| **叙述人格** —— 图志的署名者、器物的制作者 | **述层** | 这是手艺，自由 |
| 他的身世、他遇见的东西 | **幻层** | **必须明示为虚构** |

**含混本身就是价值** —— 让人分不清他是一个真实存在过的走台，还是一个被虚构出来的采集者。涩泽与盛文强都推崇「含混多义，不需要明确答案」。

⚠️ **但幻层必须明示这条不能破。**

## 八、店里的那个他

- **位置**：珍奇柜旁边。珍奇柜的传统里，收藏家的画像就挂在柜边。
- **做法**：**必须是拙的。** 手工、木刻或粗陶，可以歪、可以不对称、可以有明显手痕。
- **手里／脚边**：一个装着海玻璃的容器。**里面的东西可随时更换** —— 今天海玻璃，明天别的。**那就是这家店在做什么的说明书。**

## 九、执行红线

- ❌ **不得做成精致的树脂手办／潮玩摆件。** 一秒垮掉。宁可像村口老木匠随手削的，也不要像潮玩店里的。
- ❌ **不得给他画一张清晰的脸。**
- ❌ **不得让他开口说话／写第一人称煽情文案。** 他不解释，解释的是词条。
- ❌ **不得把「憨」做成设计出来的假憨。** 陈丹青说的是梵高**真的是生手**。精明人装笨，一眼看穿。
  - 真憨的三条路：**让不会画的人画**（素人手笔，不修）／**保留失败的痕迹**（歪的就歪着）／**用不擅长的手做**（金属工艺师去做泥塑）。
- ❌ **不得让他与「一风」争中心。** 法则在他身上，不在他之上，也不在他之外。

## 十、对各 Skill 的影响

| Skill | 变更 |
| --- | --- |
| **1 符号学** | 母体由「一风」改为「海边小子」；一风降为其计时法。符号三重身份新增「弯腰背影」 |
| **2 文创设计** | 产品线三分重挂为 **他捡的／他做的／他量的**；新增海玻璃线 |
| **3 平面视觉** | 深赭为主色（他的衣色）；版式向古籍标本档案靠；禁精致化 |
| **4 空间展陈** | 店内须有他的实体，置于珍奇柜旁；容器内容物即店铺说明书 |
| **5 器物叙事** | 图志署名为他；词条【器】栏说明"他捡的"还是"他做的" |
| **6 供应链品控** | 「精工做拙形」入 DFM：工艺精度不降，但造型不得修饰优美化 |
| **7 零售交互** | 店员话术是**替他讲解**，不是替品牌推销。他不说话 |
