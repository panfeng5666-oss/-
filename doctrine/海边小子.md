## 〇、一句话

> **海边小子是一个角色。他在退了潮的东海边捡东西。**
> **他捡到的每一样，都是下一个物件 IP。**

他不是署名、不是人格设定、不是一个"位置"。**他是一个有脸、能开模、能被单独买走的东西。**

# 一、定位与客群

## 1.1 定位

对标形态是**角色玩具 IP**（拉布布一类），不是"品牌吉祥物"：

| | 品牌吉祥物 | **角色 IP** ✅ |
| --- | --- | --- |
| 本体 | 印在别的东西上的图案 | **他自己就是商品** |
| 靠什么成立 | 靠品牌解释 | **靠一眼认出** |
| 增长方式 | 铺更多品类 | **主角不变，系列轮换** |
| 故事 | 前置，必须先讲 | **后置，可以不讲** |

**三条硬要求**：① 形象固定到能开模，定死后不许每次微调；② 他本人是第一件商品，是入口不是第十件；③ 三米外要能被认出来——读懂是加分，不是门票。

## 1.2 差异化站位 ✅

市场上的角色 IP 绝大多数是**无来历的原创造型**（好看、好卖、可替代）。海边小子的站位是 **「有来历的造型」**：脸取自玉环真实船饰，衣色取自志书记载的渔民染色，系列节拍取自真实渔汛。

**抄得走造型，抄不走来历。**

## 1.3 目标客群 🔸

| 圈层 | 画像 | 为什么会买 |
| --- | --- | --- |
| **核心** | 25–40 岁，一二线，买过潮玩但对纯萌系疲劳 | 要一个**不装可爱**的角色；材质与来历是决定项 |
| **第二圈** | 自然物与标本收藏者（矿石、贝壳、海玻璃、旧物） | L2 物件 IP 天然对味；珍奇柜逻辑就是他们的逻辑 |
| **第三圈** | 玉环／台州本地与在外的台州人 | 情感与身份认同；也是内容最早的传播源 |

⚠️ **本表未经验证**，是从产品属性反推的。首批内容发布后须用真实互动数据回填。

## 1.4 情绪价值 ✅

不是治愈，不是陪伴，不是好运。是——

> **海把活干完了，他只是弯了个腰。**

对着一个退潮的、衰退的、不再丰饶的海，他的反应不是哀悼也不是守护，是**弯腰去捡**。主动、日常、不悲壮。

（`CLAUDE.md` 已确立：**衰退的落点是「捡」**，禁用「丰饶东海」调门。）

# 二、形象设定

## 2.1 核心决定：船目就是他的脸 ✅

渔船船首那对眼睛（玉环船祭「开船目」，遗俗仍存 —— `matrix/03-民俗.md`），直接长在他脸上。

- **一眼可认** —— 一对大眼占满整张脸，三米外成立；
- **有出处** —— 不是设计师编的，是玉环船上真有的东西；
- **抄不走** —— 抄了就是抄一个有来历的东西。

## 2.2 造型参数

| 项 | 参数 | 状态 |
| --- | --- | --- |
| 头身比 | 约 **1:1**（头大身小） | ✅ |
| 脸 | **一对船目**，杏核形、黑瞳偏下、眼白多。**无鼻、无嘴** | ✅ |
| 船目开度／瞳位／眼白比 | —— | ⚠️ **卡住全部后续** |
| 姿态 | **弯腰**，一手扶膝，一手托篓 | ✅ |
| 标配 | **一个篓**（物件 IP 的接口，见第五块） | ✅ |
| 表面 | **磨砂搪胶，绝不上光油**——要海玻璃被磨过二十年的雾面 | ✅ |
| 主色 | **深赭**（「渔民衣以拷汁染，其色深赭」，县志第二十四编） | ✅ |
| 辅色 | **雾青绿**（海玻璃色），用于半透部件 | ✅ |
| 正常款尺寸 | 约 **12cm** | ⚠️ 待打样 |

**无嘴是保留项**——他不说话这条不因为有脸而废。有眼无嘴，形象上更狠，也守住"他不解释"。

## 2.3 待补的形象资产 ⚠️

角色 IP 不是一张图，是一组可复用的资产。定稿后须补齐：

- **三视图**（正／侧／背）+ 转面图（三维建模与开模的输入）
- **姿态库**：弯腰（标准态）／蹲／背身／托篓／伸手，共 5 式 🔸
- **表情库**：只有眼睛可变。眯／睁／半闭／向下看，共 4 式 🔸 —— **无嘴意味着表情全靠船目，这是设计难点也是识别点**
- **与 L2 的合影规范**：他和篓中物的标准相对位置与比例

# 三、世界观

## 3.1 边界（写到此为止，禁止扩写）✅

- **地点**：退潮之后的东海滩涂。
- **行为**：捡。只有这一个动作。
- **时间**：他按风计日，不按钟点。

**不写的**：身世、冒险、伙伴、反派、来历之谜。

## 3.2 为什么故意不写 ✅

角色 IP 的故事**后置**：先让人认出他、买走他，再让想深究的人去读《东海风物图志》。
**前置故事＝解释成本＝卖不动。** 这正是原方案「一风」难卖的病根。

## 3.3 「一风」的位置 ✅

**「一风」由母体降为他的计时法**，不再与他争中心。法则在他身上，不在他之上。
（`cases/01` 母体归一结论据此调整：母体＝海边小子。）

# 四、内容体系与节奏

## 4.1 内容先于产品（`CLAUDE.md` 已确立）✅

正常路径是「做产品→拍照→发内容→卖货」；本项目反过来：**先发内容建立可信度 → 产品是"可以带走的那部分"**。

## 4.2 内容形式 🔸

| 形式 | 内容 | 频次 | 承担 |
| --- | --- | --- | --- |
| **捡的记录** | 一次赶海：地点、潮时、捡到什么、每件的状态 | 每周 1 条 | 可信度的根 |
| **词条** | 《东海风物图志》条目，六栏体例 | 每周 1 条 | 深究者的入口 |
| **打样与工艺** | 开模、试色、失败的样 | 不定期 | **"产地"的证据** |
| **上新** | 每风一组 L2 | 一年 4 次 | 转化 |

⚠️ **渠道未定**（小红书／视频号／抖音／独立站的主次与配比）。走线上直营与分销，渠道选择直接决定内容形态，须与 4.3 一起定。

系列节拍直接挂玉环真实渔汛 —— **主题不用编，县志里现成**：

# 五、产品与商业化架构

## 5.1 三层，一个接口 ✅

```
          海边小子（L1 本体）
                │
         【 篓 】= 接口
                │
   ┌────────────┼────────────┐
 L2 物件 IP              L3 器物线
 篓里的东西（mini）      放大版（现有九件）
 3~5cm，每风一组六件      MSRP 48~1280
```

| 层 | 是什么 | 形态 | 作用 |
| --- | --- | --- | --- |
| **L1 本体** | 海边小子自己 | 12cm 搪胶（另设大号） | **入口**。认出他＝认出品牌 |
| **L2 物件 IP** | 他捡到的东西 | 3~5cm mini，可入篓／挂身／单卖 | **复购与收藏** |
| **L3 器物线** | L2 的成人放大版 | 现有九件（`cases/02`） | **利润与可信度** |

## 5.2 篓是全部机制的接口 ✅

**他本人永远不变，篓里的东西每风换一批。** 解决三件事：

1. **新品的合法性** —— 理由不是"我们又设计了一个"，是"**他又捡到了一个**"。每个新品自带来历。
2. **收藏动力** —— 集齐一整篓，不需要故事驱动。
3. **两个价格带一条线** —— L3 船目镇纸＝L2 船目 mini 的成人版；盐器组＝盐块 mini 的成人版。同一个东西，两种买法。

### 第一风 L2 六件 🔸

海玻璃 · 藤壶 · 带鱼 · 乌贼骨 · 盐块 · 船钉
（标准：`matrix/` 有条目或有出处，且**静态照片里就成立**）

## 5.3 价格带与 BOM 上限 ⚠️ 全部待核

| 层 | 品类 | MSRP 方向 | 目标毛利率 | **BOM 上限** |
| --- | --- | --- | --- | --- |
| L2 | mini 物件 | ¥69 | 65% | **¥24.15** |
| L1 | 正常款 12cm | ¥169 | 68% | **¥54.08** |

## 5.4 ⚠️ 关键商业决策：明盒还是抽盒

| | 抽盒（盲盒） | **明盒** 🔸 建议 |
| --- | --- | --- |
| 复购 | 强 | 弱 |
| 合规 | 受《盲盒经营行为规范指引》全套约束（见第十块） | 不适用 |
| 与调性 | 与"诚实、不油"冲突；赌博机制是最油的那种设计 | 一致 |
| 收藏动力 | 靠概率 | **靠"集齐一篓"** |

**建议明盒、编号明示。** 代价是复购弱于盲盒，用「集齐一篓」＋每风限量补。**这是商业决策不是执行细节，须尽早拍板**——它决定包装结构、页面、合规成本。

## 5.5 渠道与现金流（`CLAUDE.md` 已确立）✅

- 现金流来自**线上、分销、定制**，不来自门店销售；
- 门店是**产地**，KPI 是内容产出与媒体价值，不是坪效；
- **走出去四步**：① 线上直营（L1/L2 可邮寄、可拍照、无需导购）→ ② 分销（买手店、美术馆商店、书店；L1 敲门，L3 跟进）→ ③ 联名（"他捡到别人的东西"，机制天然自洽）→ ④ 授权（**必须在第七块的权利布局落定之后**）。

⚠️ **产地的诚实边界**：内容采集在玉环、设计在玉环、门店在玉环——三件必须为真。**搪胶等制造工序须诚实标注，绝不得宣称「玉环制造」。**

| # | 条目 | 说明 |
| --- | --- | --- |

## 6.2 ⛔ 禁用清单（现在即可定死）✅

**造型类**

- ❌ 不得给他加**嘴**。有眼无嘴是识别点，也是"他不解释"的执行。
- ❌ 不得改**船目形状**（杏核、瞳偏下、眼白多）。这是整个 IP 的识别核心。
- ❌ 不得把他画**站直**。标准态是弯腰。
- ❌ 不得去掉**篓**。篓是接口，没有篓就没有物件 IP 机制。

**质感类**

- ❌ **表面不得上光油。** 光亮＝潮玩感＝油。要磨砂、要雾面。
- ❌ 不得做**渐变、金属漆、闪粉、荧光**。

**调性类**

- ❌ **不得萌化讨好。** 憨 ≠ 萌：萌是被设计出来讨好的，憨是不讨好、笨拙、真诚。**憨是「审美去油」的极端形式。**
- ❌ **不得开口说话／写第一人称煽情文案。** 解释的是词条，不是他。
- ❌ **不得做「设计出来的假憨」。** 陈丹青论梵高《海边的渔夫》：「艺术史上画得巧的人太多，而画得憨却是不易」——关键是梵高**真的是生手**。精明人装笨一眼看穿。
- ❌ 不得用**年画风、庙会风、导游词腔、丰饶调门**（`东海珍奇柜纲领.md` 审美红线，对三层一律有效）。
- ❌ 不得让**「一风」与他争中心**。

**场景类**

- ❌ 不得置于与海／捡拾无关的场景（办公室、健身房、节日促销背景板）。
- ❌ 不得用于**迷信许诺**（招财、转运、保平安）。

## 6.3 「精工做拙形」总方针 ✅

| 层面 | 取向 |
| --- | --- |
| **工艺** | **精** —— 公差、咬合、涂装一样不少 |
| **造型** | **拙** —— 不追求优美流畅，允许笨重、不对称 |
| **命名** | **直** —— 「一风记」，不叫「沧海拾光·潮汐记忆仪」 |
| **文字** | **笨** —— 只陈述，不修辞 |

# 八、生命周期与阶段目标

行业通行模型为四阶段（诞生→突破→沉淀→稳定，中金潮玩系列研究）。对应到本项目：

| 阶段 | 任务 | 主要动作 | KPI 🔸 |
| --- | --- | --- | --- |
| **诞生** | 形象与可信度成立 | 形象定稿、权利落定、内容先行（捡的记录＋词条） | ⚠️ **内容产出条数**与**完读／互动率**；**不看销量** |
| **突破** | 让人认出他 | 首风 L1＋L2 上市；分销破圈；本地媒体 | 首风售罄率、复购人数、分销点位数 |
| **沉淀** | 攒住人 | 四风稳定更新；社群；二创 | 集齐率（同一人买满一篓的比例）、社群活跃、UGC 条数 |
| **稳定** | 保持在场 | 规律更新＋授权＋联名 | 授权收入占比、在场感（无断更） |

⚠️ **KPI 的具体数值全部待定**，须在首批量级与预算确定后回填（见第十一块）。

**阶段判定的硬门槛**：诞生阶段不看销量。**若在形象与内容尚未立住时就用销量考核，必然倒逼萌化与降价——那是这个 IP 唯一的死法。**

# 九、粉丝运营与二创政策

## 9.1 分层 🔸

| 层 | 是谁 | 给什么 |
| --- | --- | --- |
| **普通** | 买过一件 | 内容、上新预告 |
| **核心** | 集齐过一篓 / 复购 3 次以上 | 编号优先选、每风预售权 |
| **铁杆** | 提供过素材（卖玻璃的、讲土名的、带路赶海的） | **署名进《东海风物图志》** |

**第三层是这个项目独有的**：内容来自在地，提供素材的人应当出现在词条的出处里。这既是诚实，也是最便宜的在地关系维护。

## 9.2 二创政策 🔸 提案

| | 政策 |
| --- | --- |
| **非商业二创** | ✅ 鼓励。绘画、手作、摄影、cos 自由创作与传播，**须署名并注明角色归属** |
| **商业使用** | ❌ 须事先授权。含代工仿制、二创商品售卖、直播带货口播 |
| **红线**（二创也适用） | ❌ 不得改船目形状、不得加嘴、不得萌化改造、不得用于迷信许诺或政治宗教场景 |
| **执行** | 违规先私信沟通再动法务；**别把粉丝当侵权者打** |

⚠️ 政策条文须经法务过一遍再对外公布。

# 十、合规

## 10.1 若做抽盒（盲盒）⚠️

2023 年 6 月市场监管总局《盲盒经营行为规范指引（试行）》适用，要点：

- **不得向未满 8 周岁未成年人销售**；向 8 周岁及以上未成年人销售须依法确认监护人同意；
- **商品价值、抽取规则、抽取概率**须以显著方式对外公示；
- 存在**负面清单**（药品、医疗器械、活体动物、易燃易爆等不得以盲盒形式销售）；
- 须采取有效措施防止未成年人沉迷。

⚠️ **以原文为准**，落地前须逐条对照并留存合规记录。
→ 本项目 🔸 **建议走明盒**（见 5.4），从源头绕开这套负担。

## 10.2 一律适用

- **产地标注**：制造工序诚实标注，绝不得宣称「玉环制造」若非事实（`CLAUDE.md`）；
- **在地事实**：物种名、渔汛、土名、民俗一律须有出处，无出处则留空并标「此处需核实」（`CLAUDE.md`）；
- **食品类**（楚门海盐）：另受食品生产经营许可与标签规范约束 ⚠️ 待专项确认；
- **玩具安全**：搪胶／毛绒品类须符合国标玩具安全要求（含小件误吞警示、邻苯与重金属限量）⚠️ **须由 Skill 6 落到具体标准号与检测项**。

## 附：对各 Skill 的影响

| Skill | 变更 |
| --- | --- |
| **1 符号学** | 母体＝海边小子（角色）；一风降为其计时法；超级符号一图三义不变（一风的弧／船目的眼／弯腰的背影） |
| **2 文创设计** | 产品谱系改为 **L1 本体／L2 物件 IP／L3 器物线**；三分（他捡的／他做的／他量的）降为 L3 内部归类 |
| **3 平面视觉** | 主色深赭；**L1/L2 靠形象不靠版式**，与 L3 古籍标本档案版式分开；**产出须并入 Style Guide** |
| **4 空间展陈** | 店内 L1 实体置于珍奇柜旁；篓中内容物即"本店在做什么"的说明书 |
| **5 器物叙事** | 图志署名为他；词条【器】栏标明"他捡的"或"他做的"；**铁杆粉丝的素材署名进出处栏** |
| **6 供应链品控** | 新增搪胶／毛绒 DFM 与 QC；**玩具安全标准须落到具体标准号**；「精工做拙形」入检：造型不得修饰优美化，表面不得上光 |
| **7 零售交互** | L1/L2 **不需要话术**（靠看不靠读）；话术资源全押 L3 |
