# 海边小子 · 顶层规划

> **性质**：总 IP 顶层规划。与 `东海珍奇柜纲领.md` 并列为最高优先级 —— 珍奇柜管**东西怎么归类与呈现**，本篇管**这个 IP 是什么、怎么长、怎么卖**。
> **确立**：2026-09-07　**改判**：2026-09-07（由「无脸的叙述人格」改为**可开模、可单独售卖的角色 IP**）

---

## 〇、一句话

> **海边小子是一个角色。他在退了潮的东海边捡东西。**
> **他捡到的每一样，都是下一个物件 IP。**

他不是署名、不是人格设定、不是一个"位置"。**他是一个有脸、能开模、能被单独买走的东西。**

---

## 一、定位：角色 IP 带动物件 IP

对标形态是**角色玩具 IP**（拉布布一类），不是"品牌吉祥物"。两者的差别是硬的：

| | 品牌吉祥物 | **角色 IP** ✅ |
| --- | --- | --- |
| 本体 | 印在别的东西上的图案 | **他自己就是商品** |
| 靠什么成立 | 靠品牌解释 | **靠一眼认出** |
| 增长方式 | 铺更多品类 | **主角不变，系列轮换** |
| 故事 | 前置，必须先讲 | **后置，可以不讲** |

### 这套机制的三条要求

1. **形象固定到能开模。** 参数一旦定死不许每次微调 —— 认得出，靠的就是不变。
2. **他本人是第一件商品。** 不是九件器物之外的第十件，是**入口**。
3. **靠看不靠读。** 站在货架三米外要能被认出来。读懂是加分，不是门票。

### ⚠️ 已废除的两条旧红线

原纲领禁「画清晰的脸」「做成手办」。**做角色 IP 与这两条不兼容，予以废除。**
（保留的部分见第九节 —— 禁的是**萌化讨好**与**假憨**，不是禁脸、禁实体。）

---

## 二、形象设定

### 核心决定：**船目就是他的脸**

渔船船首那对眼睛（玉环船祭「开船目」，遗俗仍存 —— `matrix/03-民俗.md`），直接长在他脸上。

三个理由，全是硬的：

- **一眼可认** —— 一对大眼占满整张脸，三米外成立；
- **有出处** —— 不是设计师编的造型，是玉环船上真有的东西；
- **抄不走** —— 抄了就是抄一个有来历的东西，越抄越替我们说话。

### 可交付参数

| 项 | 参数 | 状态 |
| --- | --- | --- |
| 头身比 | 约 **1:1**（头大身小） | 定 |
| 脸 | **一对船目**，杏核形、黑瞳偏下、眼白多。**无鼻、无嘴** | 定 |
| 船目开度／瞳位／眼白比 | —— | ⚠️ **待定，见第十节** |
| 姿态 | **弯腰**，一手扶膝，一手托篓 | 定 |
| 标配 | **一个篓**（物件 IP 的接口，见第四节） | 定 |
| 表面 | **磨砂搪胶，绝不上光油** —— 要海玻璃被磨过二十年的雾面 | 定 |
| 主色 | **深赭**（拷汁染，「渔民衣以拷汁染，其色深赭」，县志第二十四编） | 定 |
| 辅色 | **雾青绿**（海玻璃色），用于半透部件 | 定 |
| 正常款尺寸 | **约 12cm** | ⚠️ 待打样确认 |

**无嘴是保留项。** 他不说话这条不因为有脸而废 —— 有眼无嘴，形象上更狠，也守住"他不解释"。

## 三、世界观边界（写到此为止，禁止扩写）

- **地点**：退潮之后的东海滩涂。
- **行为**：捡。只有这一个动作。
- **时间**：他按风计日，不按钟点（见第五节「一风」）。

**不写的**：身世、冒险、伙伴、反派、来历之谜。
角色 IP 的故事是**后置**的 —— 先让人认出他、买走他，再让想深究的人去读《东海风物图志》。**前置故事＝解释成本＝卖不动。**

### 他的价值观（一句，可印在盒上）

> **海把活干完了，他只是弯了个腰。**

玻璃碎了被丢进海里，海磨了它二十年，磨掉所有锋利的边。他弯腰把它捡起来 —— 他不觉得这是变废为宝。

**「衰退」的落点因此是「捡」**：哀是情绪、守是防御，**捡是主动的、日常的、不悲壮的**。
> 海退了。但退潮之后，有东西可捡。

## 四、产品架构：三层，一个接口

```
          海边小子（L1 本体）
                │
         【 篓 】= 接口
                │
   ┌────────────┼────────────┐
 L2 物件 IP              L3 器物线
 篓里的东西（mini）      放大版（现有九件）
 3~5cm，每风一组六件      MSRP 48~1280
```

| 层 | 是什么 | 尺寸／形态 | 作用 |
| --- | --- | --- | --- |
| **L1 本体** | 海边小子自己 | 12cm 搪胶（另设大号） | **入口**。认出他 = 认出品牌 |
| **L2 物件 IP** | 他捡到的东西 | 3~5cm mini，可放进篓／挂在他身上／单独买 | **复购与收藏**。集齐一整篓 |
| **L3 器物线** | L2 的成人放大版 | 现有九件（`cases/02`） | **利润与可信度** |

### 篓是全部机制的接口

**他本人永远不变，篓里的东西每一风换一批。** 这解决了三件事：

1. **新品的合法性** —— 出新品的理由不是"我们又设计了一个"，是"**他又捡到了一个**"。每个新品自带来历。
2. **收藏动力** —— 想集齐一整篓，不需要故事驱动。
3. **两个价格带一条线** —— L3 的船目镇纸就是 L2 船目 mini 的成人版；盐器组就是盐块 mini 的成人版。**同一个东西，两种买法。**

### 价格带（⚠️ 全部待核 —— 库内无角色玩具品类的成本与定价数据）

（`BOM上限 = MSRP × (1 − 目标毛利率)`，已复核）

⚠️ **这三行必须先做两件事才能定死**：① 查 `knowledge/09` 行业报告夹的潮玩品类数据；② 搪胶开模报价与首单量级 —— **模具费摊销未计入上表**，量级不定则 BOM 上限不成立。

### 与商业模式的关系（`CLAUDE.md` 已确立）

- 现金流来自**线上、分销、定制**，不来自门店销售；
- 门店是**产地**，KPI 是内容产出与媒体价值；
- **内容先于产品** —— L1 出街前，先有他捡东西的内容。

角色 IP 恰好补上了原方案最大的短板：**九件器物全部需要先读懂才觉得好，L1/L2 不需要。** 他是那个"先被看上"的门面。

## 八、走出去的路径

产地在玉环，市场不在玉环。四步，前两步是主路：

1. **线上直营** —— L1/L2 是可邮寄、可拍照、无需导购的品类，天然适合；
2. **分销** —— 买手店、美术馆商店、书店。L1 是敲门砖，L3 靠它带进去；
3. **联名** —— 他捡到别人的东西，机制天然自洽，不用改设定；
4. **授权** —— 最后一步，且必须在商标与著作权登记落定之后（见第十节）。

⚠️ **产地的诚实边界**：内容采集在玉环、设计在玉环、门店在玉环 —— 这三件必须为真。**搪胶等制造工序须诚实标注产地，绝不得宣称「玉环制造」。**

## 九、执行红线（更新版）

保留的：

- ❌ **不得萌化讨好。** 憨 ≠ 萌 —— 萌是被设计出来讨好的，憨是不讨好、笨拙、真诚。**憨是「审美去油」的极端形式。**
- ❌ **不得开口说话／写第一人称煽情文案。** 有眼无嘴。解释的是词条，不是他。
- ❌ **不得做「设计出来的假憨」。** 陈丹青论梵高《海边的渔夫》：「艺术史上画得巧的人太多，而画得憨却是不易」—— 关键是梵高**真的是生手**。精明人装笨一眼看穿。
- ❌ **表面不得上光油。** 光亮＝潮玩感＝油。要磨砂、要雾面。
- ❌ **不得让「一风」与他争中心。** 法则在他身上，不在他之上。

废除的：~~不得画清晰的脸~~、~~不得做成手办~~（见第一节）。

### 「精工做拙形」仍然是总方针

| 层面 | 取向 |
| --- | --- |
| **工艺** | **精** —— 公差、咬合、涂装一样不少 |
| **造型** | **拙** —— 不追求优美流畅，允许笨重、不对称 |
| **命名** | **直** —— 「一风记」，不叫「沧海拾光·潮汐记忆仪」 |
| **文字** | **笨** —— 只陈述，不修辞 |
