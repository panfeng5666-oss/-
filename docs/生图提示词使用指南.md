# 生图提示词粘贴到哪里执行

> 这是 `需求来源-GeminiSpark导出.md` 第 16 轮"设计提示词我复制到哪里设计？"的补答 —— 原对话中该问题未被回答。

本库产出的 Prompt 分两类，去处不同：

| Prompt 类型 | 产出系统 | 用途 | 执行工具 |
| --- | --- | --- | --- |
| 产品/包装效果图 | 平面与视觉设计系统 | 提案图、电商主图、打样前预览 | Midjourney / 即梦 / 可灵 / Firefly / SD |
| 空间展陈效果图 | 空间展陈与场景化设计系统 | 展台提案、施工前沟通 | 同上 |

## 一、Midjourney（本库 Prompt 的原生目标工具）

**方式 A · 网页版（推荐，更省事）**

1. 打开 `midjourney.com`，用 Discord 或 Google 账号登录（需订阅付费计划，约 $10/月起）。
2. 进入 **Create** 页面，把 Prompt 完整粘进顶部输入框。
3. 回车，等 60 秒左右出 4 张图。点单张可 **Upscale**（放大出图）或 **Vary**（微调重绘）。

**方式 B · Discord**

1. 加入 Midjourney 官方 Discord 服务器，进入任一 `#newbies` 频道（或把 Midjourney Bot 加到自己的服务器）。
2. 输入 `/imagine`，回车后在 `prompt` 栏粘贴 Prompt。
3. 回车出图，用图下方的 `U1~U4` 放大、`V1~V4` 微调。

**参数含义**（本库 Prompt 末尾那串）：

- `--ar 3:4` 画面比例（3:4 竖构图，适合电商主图与小红书；横图用 `--ar 4:3` 或 `--ar 16:9`）
- `--style raw` 关闭 MJ 的自动美化滤镜，更接近真实商业摄影
- `--v 6.0` 指定模型版本；若你的账号已是更新版本，可直接删掉这个参数用默认版本

## 二、国内工具（即梦 / 可灵 / 通义万相 / 文心一格）

这些工具**不认 `--ar --style --v` 参数**，直接粘会把参数当成画面描述。正确做法：

1. 把 Prompt 里 `--` 开头的部分**全部删掉**，只保留描述正文。
2. 比例改用界面上的比例按钮（选 3:4 或 9:16）。
3. 若工具中文效果更好，可把描述正文译成中文再投；本库 Prompt 刻意只用"可被相机还原的名词与参数"，翻译不会掉信息。

## 三、Adobe Firefly

`firefly.adobe.com` → Text to Image → 粘贴描述正文（同样删掉 `--` 参数）→ 右侧面板选 Aspect ratio 与 Content type（选 Photo）。商用授权较清晰，适合正式提案。

## 四、Stable Diffusion（ComfyUI / WebUI，本地部署）

适合需要**同一构图反复微调**或**批量出图**的场景：

- 描述正文放 **Positive prompt**；
- 建议加 Negative prompt：`text, watermark, logo, distorted proportions, plastic look, oversaturated`；
- 分辨率按 3:4 设（如 896×1152），采样步数 30 左右；
- 想锁定构图，配 ControlNet 用手绘草图或刀版图做参考。

## 五、出图后的落地纪律

AI 出图是**提案沟通稿，不是打样依据**。交付印厂与工厂时必须以以下文件为准：

- 平面：刀版 AI/PDF 文件 + Pantone 色号 + 工艺标注（见平面与视觉设计系统）
- 产品：技术交底书 TSS + 公差标注图（见供应链工程与打样品控系统）

AI 图常见失真项，提案时要主动说明：字体会乱码、Logo 会变形、材质接缝与结构不可制造、尺寸比例不准。
